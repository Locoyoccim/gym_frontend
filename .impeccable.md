## Design Context

### Users
Personas serias que van al gimnasio regularmente — atletas recreativos o competitivos que usan la app durante o después de sus entrenamientos para registrar rutinas, series, y revisar historial. El contexto de uso es el gym: luz artificial fuerte, manos a veces ocupadas, concentración en el entrenamiento. Mobile-first. No casual.

### Brand Personality
**Tres palabras**: Disciplinada. Pesada. Precisa.

El tono es el de un cuaderno de entrenamiento profesional — no la energía hiperactiva de una app consumer fitness, sino la seriedad de un atleta que lleva registro meticuloso. Como un entrenador de alto rendimiento: directo, sin adornos, orientado a datos.

### Aesthetic Direction
**Dark mode** — absoluto. El gym es un espacio oscuro de concentración.

**Color acento**: Ámbar forja — `oklch(70% 0.18 62)` — el color del hierro calentado en una fragua. Cálido, intenso, sin la agresividad del rojo de peligro. Evoca trabajo físico real, metal, temperatura. Completamente distinto al rojo genérico actual.

**Tipografía**:
- Display / Números / Datos: **Chakra Petch Bold** — estética de display de cronómetro deportivo, lectura técnica, precisa. Perfecta para pesos, series, repeticiones.
- UI / Cuerpo: **Barlow** — limpio, funcional, ligeramente militar. Legible en condiciones de gym.

**Paleta base** (OKLCH):
- Background: `oklch(8% 0.006 62)` — negro cálido, no puro
- Surface: `oklch(13% 0.009 62)` — tarjetas / contenedores
- Surface elevated: `oklch(18% 0.010 62)` — inputs, elementos elevados
- Border: `oklch(28% 0.012 62)` — bordes sutiles
- Text primary: `oklch(92% 0.008 62)` — casi blanco, cálido
- Text secondary: `oklch(62% 0.010 62)` — gris cálido para labels
- Accent: `oklch(70% 0.18 62)` — ámbar forja
- Accent muted: `oklch(40% 0.12 62)` — acento para estados desactivados

**Estética visual**: Precisión industrial — tablas de chalk en el gimnasio, planillas de competencia, software de ciencias del deporte. Sin decoración. Sin glassmorphism. Sin gradientes en texto. La información ES el diseño.

**Anti-referencias**: No Nike/Adidas consumer fitness. No neon-on-dark gaming. No ilustraciones. No gradientes purple-to-blue.

### Design Principles
1. **Los datos son el héroe** — pesos, series, repeticiones deben ser inmediatamente legibles, tipografía grande y contrastante
2. **Zero friction** — un atleta con las manos cansadas debe poder registrar una serie en 3 toques
3. **Densidad informada** — mostrar bastante información sin sentirse abrumada; jerarquía tipográfica fuerte
4. **Oscuridad intencional** — no dark-mode por defecto, sino dark como parte de la identidad
5. **Sin adornos** — cada elemento visual debe justificarse funcionalmente; si no ayuda a entender los datos, se elimina
